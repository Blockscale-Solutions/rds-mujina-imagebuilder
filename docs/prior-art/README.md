# Prior art

Projects we studied while designing this build environment. We note that they exist and link to
them; we do not reproduce their code, text or designs here. Each has its own licence.

| project | what it is | where |
|---|---|---|
| Braiins OS | An open-source (GPL-3.0) OpenWrt-based firmware for commercial Bitcoin miners, with its own build, install and upgrade tooling. Its current releases are closed, but the vendor publishes a changelog. | [github.com/braiins](https://github.com/braiins), [changelog](https://academy.braiins.com/braiins-os/whats-new) |
| FutureBit Apollo OS | The software of FutureBit's Apollo home miners: a web dashboard and API over a full Bitcoin node. The source is published under CC BY-NC-ND 4.0 (study only). | [apolloapi-v2](https://github.com/jstefanop/apolloapi-v2), [apolloui-v2](https://github.com/jstefanop/apolloui-v2), [futurebit.io](https://www.futurebit.io/) |
